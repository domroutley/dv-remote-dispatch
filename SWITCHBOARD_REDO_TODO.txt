[ ] 2.2 JunctionMapper.cs - BFS Pathfinding Algorithm
     - Method: FindPathsWithSwitchStates(startJunctionIdx, targetJunctionIdx)
       * Returns: List of (path, switchStateMap) tuples
       
     - CRITICAL FIX FROM HISTORY: Track EDGE visits, not NODE visits!
       * WRONG: HashSet<int> visitedNodes
       * CORRECT: HashSet<(int fromNode, int toNode)> visitedEdges
       * Reason: Same junction can be reached via different switches/states
       
     - Algorithm outline:
       Queue<(List<int> path, Dictionary<string,string> switchStates)> queue;
       HashSet<(int, int)> visitedEdges;  // <-- KEY FIX
       
       while queue not empty:
         pop (path, states)
         current = path.Last()
         
         if current == target: return (path, states)
         
         foreach neighbor of current:
           edge = (current, neighbor)
           if edge NOT in visitedEdges:
             mark edge as visited
             newStates = states + any switch changes
             push (path + [neighbor], newStates)

[ ] 2.3 JunctionMapper.cs - Switch State Mapping
     - Method: GetSwitchMappingForTrack(trackId)
       * Input: track identifier
       * Output: Dictionary<gameJunctionIdx, List<path_with_switch_states>>
       
     - For each game junction, compute all reachable paths with their switch configs
     - Cache results to avoid recomputation on every request

[ ] 2.4 HttpServer.cs - API Endpoints
     - Endpoint: GET /junctionMapping/build
       * Triggers full graph rebuild from current game state
       * Returns: { "trackCount": N, "junctionCount": M }
       
     - Endpoint: GET /switchboard/data
       * Returns complete switchboard data structure:
         {
           "tracks": [...],
           "switchMappings": {...},
           "currentSwitchStates": {...}
         }
         
     - Endpoint: GET /res/{path}
       * CRITICAL: Use fully qualified resource name
       * Format: $"RemoteDispatch.{path.Replace('/', '.')}"
       * Example: "/res/frontend/res/switchboard-layout.json" 
                 -> "RemoteDispatch.frontend.res.switchboard-layout.json"
